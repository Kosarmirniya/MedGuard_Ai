# 🩺 MedGuard AI

> Intelligent Healthcare Risk Assessment Platform

MedGuard AI is a machine-learning powered healthcare risk assessment API built with Python and FastAPI.

## 🚀 Features

- Machine Learning risk assessment
- Random Forest classification
- FastAPI REST API
- SQLite database
- SQLAlchemy
- Patient CRUD operations
- Risk prediction and probabilities
- Automated testing with Pytest
- Swagger API documentation

## 🛠️ Technologies

- Python
- FastAPI
- Scikit-learn
- Pandas
- SQLAlchemy
- SQLite
- Pytest
- Joblib
- Git & GitHub
